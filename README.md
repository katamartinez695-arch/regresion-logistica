# Regresión Logística

## Introducción al Machine Learning

Proyecto semanal de exploración computacional de la regresión logística.

**Universidad El Bosque**  
**Programa de Matemáticas y Estadística**  
**Semestre 2026-2**

## Objetivo

Estudiar computacionalmente propiedades concretas del modelo
logístico mediante experimentos reproducibles y resultados
cuantitativos.

El proyecto aborda:

- Superficie del riesgo logístico.
- Datos separables y no separables.
- Recuperación de parámetros.
- Interpretación de los parámetros.
- Verosimilitud y estabilidad numérica.
